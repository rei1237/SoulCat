# 사주보는 고양이 영냥이

사용자가 제공한 일러스트로 구성한 모바일 메인. Next.js 15 / React / TypeScript / 정적 내보내기.

## 실행

```powershell
cd C:\Users\user\Desktop\SoulCatProject
npm install
npm run dev
```

프로덕션 빌드 미리보기:

```powershell
npm run build
npm run preview
```

http://127.0.0.1:3000 에서 확인한다. 동일한 폴더의 개발 서버와 빌드를 동시에 실행하지 않는다. 개발 서버를 종료한 뒤 빌드한다. `out/`은 정적 배포 산출물이며 외부 배포는 수행하지 않았다.

## 구현 범위

- 모바일 중심 Hero, 쓰다듬기 반응, 첫 화면 60px CTA.
- 프롤로그 배너와 8장면 시네마틱: 두 가상 대통령의 운명 → 하늘의 판결 → 고양이 변신 → 고등어 → 영냥이의 점술방.
- 고민별 안내, 6개 서비스의 2열 카드, 초융합 소개, 추천 가로 목록.
- 제공된 로그인/회원가입 문 일러스트를 쓰는 계정 진입 패널.
- 오늘의 한마디 및 문구 복사. 한마디 보관 기능은 사용하지 않는다.
- 낮/밤 휴식 이미지, 흰 배경 표정 전환과 6프레임 걷기. 무한 재생 없이 탭 한 번당 1.2초. 모션 감소 설정 반영.
- 키보드 포커스, Escape 닫기, 모달 포커스 복귀, safe-area.

## 실제 서비스와의 경계

운세 계산, 생년월일 입력, AI 대화, 실제 로그인/회원가입, 결제, 서버 보관함은 이번 메인 작업에 포함되지 않았다. 관련 패널에 준비 상태를 표시하며 개인정보나 비밀번호를 받지 않는다. 무료 CTA는 개인 사주 해석이 아닌 편집된 오늘의 한마디 체험으로 연결된다. KST 날짜에 따라 한마디를 선택하며 예언이나 개인화 결과라고 표현하지 않는다. 오늘의 한마디는 저장하지 않는다.

SoulCat 결제는 꿀꿀 운세의 기존 결제 권리와 별개로 운영한다. 설정 문서에 있는 생선 화폐 및 예시 가격도 검증 없이 새로 도입하지 않았다. 추천/초융합은 사용자가 요청한 UI 소개이며 출시·판매 실적을 주장하지 않는다.

## 수정 위치

- `src/components/FortuneHome.tsx`: 메인 구성, 탐색 및 인터랙션.
- `src/data/home.ts`: 운세 설명, 고민 연결, 한마디, 프롤로그 원고.
- `src/app/globals.css`: 반응형 레이아웃, 디자인 토큰, 짧은 모션.
- `scripts/prepare-assets.mjs`: 사용자 원본의 크롭/리사이즈/WebP 파생 파일 생성.
- `docs/asset-manifest.json`: 에셋별 원본 파일, 크롭 좌표, 해상도, 크기 및 투명도.

원본 에셋은 수정하지 않는다. `SOULCAT_ASSET_DIR` 환경변수로 원본 폴더를 지정할 수 있다. 출처는 manifest와 WebP XMP에 기록했다. 사용자가 제외한 `과거 회상.webp`의 두 뒷모습 장면은 공개 에셋에 포함하지 않는다. `docs/asset-contact-sheet.jpg`는 원본 조사 기록이며 웹으로 배포되지 않는다.

## 검증

```powershell
npm run typecheck
npm run build
npm run preview
# 별도 터미널
npm run test:ui
```

설치된 Chrome을 사용한다. 360×800, 375×812, 390×844, 412×915, 430×932, 768×1024, 1440×1000에서 캡처·가로 넘침·CTA·이미지·접근성을 검사한다. 실제 동작 검증과 결과는 `docs/ui-verification.json`, 이미지는 `docs/screenshots/`에 남긴다. 성능 수치는 로컬 Chrome 측정이며 실제 모바일 회선/기기 성능 보장이 아니다.


영냥이의 방은 `/room/`에서 볼 수 있습니다. 수다방도 이 방으로 연결되고 프롤로그는 방 안에서 열립니다. 질문 입력은 현재 서버 전송 없이 준비된 안내 질문으로 고민을 정리하는 UI이며 실제 자유 상담 API는 아직 연결하지 않았습니다. 방을 벗어나면 입력 기록은 사라집니다. 추가 검증은 `node scripts/verify-room.mjs`, `node scripts/verify-prologue.mjs`로 실행합니다. 상세 변경 및 제한은 `docs/PROLOGUE-DELIVERY.md`를 참조합니다.
