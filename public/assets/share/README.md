# Share rendering assets

Cat and fish PNGs are resized derivatives of SoulCat's existing licensed project assets (`public/assets/fortune/saju-illustration.webp` and `public/assets/fish/`). The four original fish retain their existing artwork. Assorted and omakase use newly generated, project-owned product illustrations; see docs/FUSION-IMPLEMENTATION.md.

`noto-kr.otf` is a subset of Noto Sans CJK KR Regular, downloaded from:
https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf

Subset coverage: basic Latin, Hangul Jamo, Hangul compatibility Jamo, Hangul syllables and common punctuation. Generated using fontTools subset for server-side SVG rasterization. Original SIL Open Font License is retained in `FONT-LICENSE.txt`.

Share rendering does not request a language model or an image generation model.
