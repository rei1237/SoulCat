# 모바일 메인 구현 보고

## 수정한 파일

- `src/components/FortuneHome.tsx`: 메인 화면과 프롤로그·계정 진입·운세 소개 패널, 키보드 및 상태 처리.
- `src/app/globals.css`: 360–430px 중심 레이아웃, 태블릿/데스크톱 확장, safe-area, 모션 감소 설정.
- `src/data/home.ts`: 재사용 가능한 서비스·고민·프롤로그·오늘의 한마디 데이터.
- `src/app/layout.tsx`, `src/app/page.tsx`: Next.js 진입점, 한국어 폰트, viewport와 미리보기용 noindex.
- `public/assets/`, `scripts/prepare-assets.mjs`: 원본을 보존한 27개 WebP 파생 에셋과 출처 기록.
- `scripts/verify-ui.mjs`, `scripts/serve.mjs`: 브라우저 검증 및 정적 빌드 미리보기.
- `package.json`, `package-lock.json`, `next.config.ts`, `tsconfig.json`: 빈 작업 폴더의 실행 환경.

## 수정 의도

메뉴보다 영냥이가 먼저 보이는 점술방을 구현했다. 데스크톱 이미지를 통째로 축소하지 않고, 모바일에서는 제목 → 큰 영냥이 → 60px CTA → 압축된 프롤로그 → 고민 → 2열 운세 순서로 다시 배치했다. 흰 배경 시트는 아이보리 무대에서 쓰며 흰 털을 제거하지 않는다. 표정 3개와 걷기 6프레임은 사용자가 눌렀을 때만 반응한다.

설정의 도도하지만 다정한 말투를 사용하고 '~냥' 어미는 제외했다. 인간 뒷모습과 고양이가 함께 있는, 사용자가 거부한 두 회상 장면은 배포 에셋에서 제외했다.

## 유지한 정책 / 미변경 영역

이용권·월정석·단건 결제 구조, 가격, 인증, API, DB, 계산 엔진을 만들거나 변경하지 않았다. 이 빈 프로젝트에는 기존 서비스 연결이 없다. 생선 등급 가격 및 화폐를 도입하지 않았다. 출시·판매 순위를 의미하는 BEST 주장도 추가하지 않았다.

계정 화면은 제공된 로그인/회원가입 일러스트를 사용한 진입 UI이며 실제 가입과 인증은 준비 중이다. 무료 버튼은 편집된 오늘의 한마디를 연다. 개인 사주 해석이 아님을 안내한다. 보관함은 향후 운세 리포트용 준비 안내만 제공한다. 오늘의 한마디 보관 기능은 사용자 요청으로 제거했다.

## 검증한 명령

- `npm run assets`
- `npm run build` — 정적 내보내기 성공. 메인 첫 로드 JS 약 114 kB.
- `npm run typecheck`
- `npm run test:ui`
- Impeccable mechanical detector — 발견 항목 0개.
- Impeccable provenance scan — 27개 이미지의 출처 확인, 누락 0개.
- 실제 Chrome Lighthouse navigation/mobile — 접근성 100, Best Practices 100. 성능 카테고리를 측정하지 않는 도구이므로 성능 점수로 해석하지 않는다.

360×800, 375×812, 390×844, 412×915, 430×932, 768×1024, 1440×1000 캡처와 자동 검증을 수행했다. 모든 크기에서 가로 넘침/깨진 이미지/JS 오류/axe WCAG A·AA 발견 항목은 없었다. 모바일 5개 뷰포트의 로컬 CLS는 0. 실제 회선·기기 성능 수치가 아니다.

첫 화면 CTA 하단 위치: 360px에서 603px, 390px에서 631px, 430px에서 668px. 각 하단 내비게이션 시작 위치는 728px/772px/860px로 CTA를 가리지 않는다.

동작 검증: 고양이 탭, 한마디 보관 UI 제거, 보관함 준비 안내, Escape 및 포커스 복귀, 로그인·회원가입 이미지 전환, 프롤로그 4장면과 종료, 고민별 추천, 가로 캐러셀, 표정 전환, 1.2초 걷기 종료, 모션 감소. 홈↔운세 및 소개 패널→운세 메뉴의 선택 상태도 회귀 검증했다. 별도 최종 검사에서 브랜드 링크의 접근 가능한 이름을 화면 문구와 일치시켰고, 6프레임 걷기 진행/종료 및 모션 감소를 재확인했다(docs/final-checks.json).

독립 마무리 리뷰의 두 수정 항목(메뉴 선택 상태, 불필요한 헤딩 위 라벨)은 모두 resolved / 해당 수정 범위 ship 판정을 받았다.

## 추가 확인이 필요한 부분

- 실제 운세 엔진, 로그인/가입, 결제, AI 상담, 서버 보관함 연동은 별도 작업이다.
- 실제 iOS Safari/Android 기기의 safe-area 및 저속 네트워크 체감 검증은 아직 하지 않았다.
- 미리보기는 의도적으로 noindex 상태다. SEO 점수 63은 출시 전 검색 차단의 영향을 받는다. 외부 배포 및 도메인 연결은 수행하지 않았다.

실행 방법은 `README.md`, 원본 추적은 `docs/asset-manifest.json`, 캡처는 `docs/screenshots/`, 검사 수치는 `docs/ui-verification.json`을 참조한다.
