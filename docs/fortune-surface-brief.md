# 운세 화면 확장

Mode: Operate → Read. 기존 달빛 점술방 시각 언어를 유지하고 사용자가 제공한 사주 카드 스크린샷의 2열 이미지/짧은 설명 구성을 적용.

사주: 기질/연애/대운/직업/재물 카드를 먼저 선택. 숙요: 궁합과 두 프로필 입력 우선. 베다/서양/자미는 각 체계의 상담 주제를 별도로 노출.

4종 생선은 카테고리와 독립된 가격 선택. 서버 catalog 응답으로만 실제 금액 표시. 로컬 모의 구매는 '개발용/청구 없음'으로 명시하며 공개 preview 판매는 비활성.

의도한 화면 한정 확장: 연노랑 #f5efc3, 연두 #e3edc2, 하늘 #cfeaf0, 라벤더 #e3dcf4, 복숭아 #f7e2cc. 첨부 카드 구성에 맞춘 종이색이며 메인 디자인 색상을 교체하지 않는다. Impeccable 검사 결과는 이런 palette/type/radius 추가에 대한 advisory이며 구조적 오류 발견은 없다.
